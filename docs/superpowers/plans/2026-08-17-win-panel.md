# Win Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a floating HUD panel that appears after a full-power protest win, showing randomized theme-appropriate copy, a "next random sticker" action, and a share row (existing channels + copy-link) — without pausing the crowd underneath.

**Architecture:** Two new modules — a pure data module (`src/hud/winCopy.ts`) and a self-contained HUD component (`src/hud/WinPanel.ts` + `src/hud/winPanel.css`) built on the shared `hudGlass.css` tokens, following the exact construction/lifecycle pattern already used by `MenuPanel.ts` (overlay + panel, `attachTo`/`show`/`hide`/`destroy`, native-share-with-icon-row-fallback, toast-on-copy). `main.ts` wires it into the existing `onProtestWin` callback and the existing `replaceOverlay`/`getFaceStickerDefs` sticker-swap path — no changes to `RaidController`.

**Tech Stack:** TypeScript 5.x (`erasableSyntaxOnly`, `verbatimModuleSyntax`), Vite, vitest + happy-dom, vanilla DOM (no framework), CSS custom properties from `hudGlass.css`.

**Styling guidance:** Tasks that touch `winPanel.css` should apply `high-end-visual-design` and `frontend-design:frontend-design` principles (spacing rhythm, type scale, motion easing, contrast) while staying inside this app's existing visual language — reuse `--hud-glass-*` tokens from `hudGlass.css` and mirror `menuPanel.css`'s card/button/toast constructions (see Task 2 and Task 4) rather than inventing a new style.

- [ ] **Step 4: Write the implementation**

```ts
// src/hud/WinPanel.ts
import "./winPanel.css";
import { pickWinCopy, type WinCopyVariant } from "./winCopy";

const SVG_CLOSE = `<svg width="12" height="12" viewBox="0 0 14 14" fill="none" xmlns="http://www.w3.org/2000/svg"><path d="M1 1L13 13M13 1L1 13" stroke="currentColor" stroke-width="1.6" stroke-linecap="round"/></svg>`;

export class WinPanel {
  private readonly overlay: HTMLElement;
  private readonly panel: HTMLElement;
  private readonly titleEl: HTMLElement;
  private readonly copyEl: HTMLElement;
  private isOpen = false;

  constructor() {
    this.overlay = document.createElement("div");
    this.overlay.className = "win-panel-overlay";

    this.panel = document.createElement("div");
    this.panel.className = "win-panel";
    this.overlay.appendChild(this.panel);

    const closeBtn = document.createElement("button");
    closeBtn.type = "button";
    closeBtn.className = "win-panel-close";
    closeBtn.setAttribute("aria-label", "Close");
    closeBtn.innerHTML = SVG_CLOSE;
    closeBtn.addEventListener("click", () => this.hide());
    this.panel.appendChild(closeBtn);

    this.titleEl = document.createElement("h2");
    this.titleEl.className = "win-panel-title";
    this.panel.appendChild(this.titleEl);

    this.copyEl = document.createElement("p");
    this.copyEl.className = "win-panel-copy";
    this.panel.appendChild(this.copyEl);
  }

  attachTo(container: HTMLElement): void {
    container.appendChild(this.overlay);
  }

  show(variant: WinCopyVariant = pickWinCopy()): void {
    this.titleEl.textContent = variant.title;
    this.copyEl.textContent = variant.copy;
    this.isOpen = true;
    this.overlay.classList.add("open");
  }

  hide(): void {
    if (!this.isOpen) return;
    this.isOpen = false;
    this.overlay.classList.remove("open");
  }

  isPanelOpen(): boolean {
    return this.isOpen;
  }

  getRoot(): HTMLElement {
    return this.overlay;
  }

  destroy(): void {
    this.overlay.remove();
  }
}
```
