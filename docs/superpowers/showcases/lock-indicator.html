Locked-Subject Indicator Options

PR2 Task 6 — visual decision gate for the "tap-to-lock" feedback state. Each mock shows the indicator rendered around an 80px subject card on canvas.

A
Amber Ring
A 2px solid amber circle, 6px outside the subject edge. High contrast, minimal footprint.
  • Pro: unmistakable, cheap to render, readable at distance
  • Pro: color-codes "active/selected" consistently with HUD
  • Con: can clash with subject's own border/shadow
  • Con: sharp geometric feel; less "organic" for the art style
B
Gold Glow (PR1 Archetype)
Radial gold halo + soft inner ring, ~14px radius. Reuses PR1 collective-effect glow shape at lower intensity.
  • Pro: harmonizes with existing attack VFX palette
  • Pro: soft edges avoid hard clipping near canvas edge
  • Con: larger footprint (~28px) risks overlap with neighbors
  • Con: can be misread as "under attack" during collective charge
C
Dashed Paper-Cut Outline
Rotating dashed circle in cream/paper tone, ~8px outside. References the project's paper-cut edge aesthetic.
  • Pro: thematically on-brand with paper-cut UI language
  • Pro: dashed pattern reads "selected outline" without color
  • Con: rotation animation adds continuous render cost
  • Con: low contrast on dark canvas; may vanish at small sizes
D
Implicit (No Indicator)
Lock state is shown only in HUD (highlighted card, "LOCKED" badge). Canvas subject is unchanged.
  • Pro: zero render cost, zero visual clutter
  • Pro: forces user attention to HUD for state awareness
  • Con: hard to tell which subject is locked in multi-subject scenes
  • Con: breaks direct-manipulation feedback loop
