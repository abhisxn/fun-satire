ATTACK CTA — no-lock behavior

What should the ATTACK button do when no subject is locked?

PR2 · Task 7 · Lane 1 · multi-subject-targeting-design.md §3

A
CTA disabled until a subject is locked

The ATTACK button is greyed out whenever lockedSubjectId === null. Tapping a subject locks it; only then can the CTA fire. The press/hold charge-burn flow stays untouched when locked.

tap a subject to lock
locked: — none — Attack
  • Explicit targeting. Every press hits an obviously-locked subject — no surprise victims.
  • One tap more. First-time users have to discover tap-to-lock before ATTACK works.
  • Trivial state machine. ATTACK onClick reads lockedSubjectId; the null branch is unreachable.
  • Discoverability cost. New users may think the button is broken if they don't see the lock cue — pairs tightly with the lock indicator from Task 6.
  • Accessibility win. aria-disabled + clear "why" hint is standard screen-reader fare.
Plan calls this out as the simpler default if Option B is rejected.
B
CTA enabled — targets nearest subject to cursor

The ATTACK button is always active. When lockedSubjectId === null, pressing it resolves the target by Euclidean distance from the press point to each live subject and calls PowerController.tryPress(nearestId, ...). A faint dashed line previews the target so the user sees who's about to get hit.

→ nearest
locked: — none — · target: subj@175,48 Attack
  • Zero extra taps. ATTACK just works — fastest path from idle to burning.
  • Ambiguity on dense crowds. When several subjects are within a few pixels, "nearest" can flip between frames; the aim line keeps it legible.
  • Surprise damage. Misclicks on the CTA — not on a subject — still hurt someone. Risk for desktop and touch users alike.
  • More code paths. ATTACK onClick needs a "resolve target" branch on top of the locked path; two callers of PowerController.tryPress instead of one.
  • Better pairing with gaze/auto-mode. The crowd already follows the cursor (look-at), so nearest-to-cursor is a natural "cursor is the target" mental model.
Plan calls this out as the alternative — pick if zero-friction is the priority.
